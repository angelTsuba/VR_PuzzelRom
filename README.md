# VR_PuzzelRom

## Descripción
Una experiencia VR para estimular la mente mediante la Torre de Hanoi (u otros a futuro incierto)

## Integrantes
- Angel Lopez
- Brian Torres

## Tecnologías
- Unity versión 2022.3.33f1
- C#
- VR (meta quest3)

## Objetivo
Permitir al usuario resolver la Torre de Hanoi mediante interacción directa en realidad virtual.

## instrucciones
Abre el proyecto e ingresa directamente a la experiencia. Y disfruta del puzzle de la torre de hanoi.
con los controles, agarra de manera directa o atrabes del distance grab, como prefieras, y sigue las instruciones que encontraras dentro de la sala.
